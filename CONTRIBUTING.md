# Contributing

Help make offers clearer, not louder.

For an offer: use original short factual wording, a real retailer source, eligibility, exclusions and expiry. State who earns any referral reward and what the shopper receives. Do not replace someone else’s referral or label an untested checkout as working.

For code: describe the problem, show the resulting behaviour and add tests for meaningful changes. Submit a small pull request. Check the mobile experience and keyboard use. Never include secrets, production fixtures, reports, subscriber details, private screenshots or unrelated personal files.

Run the installation, build and tests in README.md. Changes need maintainer review. Passing tests alone does not authorise a production deployment. Untrusted pull-request jobs receive no production credentials and never run against the live database.

Content revisions retain attribution. Disputes belong in source-based discussion; moderation decisions can be appealed to the maintainer. The owner controls role changes. Do not use public issues for private security reports.

By submitting original code for inclusion, you license it under this project's AGPL-3.0-only software licence. Original offer text submitted through the contribution flow is offered under CC BY-SA 4.0; acceptance retains your chosen public attribution. You keep ownership of your work. Submit only material you have the right to contribute; retailer artwork, text and other third-party material are not relicensed by this project. Brand assets follow BRAND-RIGHTS.md.

Public source contribution is open. On-site contributor registration remains closed until real sign-in and production checks pass. Maintainer: [@valavaiau](https://github.com/valavaiau).
